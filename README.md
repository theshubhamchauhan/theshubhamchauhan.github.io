## About the website

A responsive, static portfolio site for GitHub Pages. It uses plain HTML, CSS,
and JavaScript, with interactive advertising-platform filters and a light/dark
theme toggle. Web hosting and cloud experience have a separate section. No build
step or package installation is required.

## Publish with GitHub Pages

1. In the repository settings, open **Pages**.
2. Select the `main` branch and `/ (root)` as the publishing source.
3. Save. GitHub Pages will publish `index.html` from the repository root.

## Personalize before publishing

- Update the display name and wording in `index.html` if your details change.
- Review the platform names and experience descriptions for accuracy.

## Privacy and security

GitHub Pages serves static files. HTML, CSS, JavaScript, and any content
included in the site are visible to visitors; client-side code cannot hide
secrets. Do not put passwords, API keys, private client information, or other
confidential details in this repository or in the published site.
